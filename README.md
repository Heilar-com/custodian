# custodian

A civic information layer: raw-capture discourse, preserved disagreement, and an incentive-transparent research mirror. Independent nodes provide audit trails so coherence issues in research and claims stay visible rather than quietly resolved.

**Status**: Thinking artifact / manifesto + contract spine. No production code yet. Connections are still arising from incomplete data. Metaphoric language (organism, cascade) lives in the slide deck; the entry stays clinical.

## Core idea

People talking first. Topics emerge from open discourse. Research is the mirror that shows where those topics rest on coherent or incoherent ground — where claims are supported by transparent methods and funding, and where they show integrity gaps (undisclosed ties, suppressed nulls, paper-mill patterns, selective reporting). AI’s job is to keep both visible so nothing true-shaped is quietly deleted.

Three primitives:
- **Verifiability** (audit trail, not truth)
- **Disagreement preserved**
- **Incentive transparency**

## How the pieces currently fit

- **Open mode**: humans only → discourse map + dark regions.
- **Scoped mode**: room chooses a topic → agent injects symmetric provenance from the graph (nearest supporting and contradicting sources, funding trails).
- **Bridging**: system can propose productive pairings across rooms via revocable, consent-per-proposal join keys.
- **Behavioral patterns**: fingerprints (talk ratios, claim repetition, narrow citations, high fallacy density) as metadata only. No in-meeting interruption. Flags are themselves challengeable.
- **Seed path**: public named-speaker nodes (Congress / parliamentary transcripts) first for traction, then anonymous citizen tables. Podcasts as another named class.
- **Voice**: used only for proof of consent and capture quality, never to label intent or character.

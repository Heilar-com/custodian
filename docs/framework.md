# Framework

> Status: a small ontology (2026-10-28). Not a decision, and no `decision` node. The film shows this picture. It is groundwork, not a complete account. Exploration stays in [video-outline.md](video-outline.md). This file is not the claim graph in [graph-schema.md](graph-schema.md).

A part that cannot change has left this foundation. A field with no parts cannot be shown. The aim is a living structure between those two failures. Believing a part finished is treated here as an error.

## Ontology

An ontology here is a set of types, a set of relations, and the rules that keep them from collapsing into each other. This file is that set.

It became one when zoom was allowed. A node at one scale may be a graph at the next. A graph may be a node in a larger graph. The types survive that zoom. That is the commitment. There is no required top graph and no required bottom atom. There is no required center.

What it is not:

- It is not a claim that the world contains only these types.
- It is not a tested theory.
- It is not encoded. No checker runs on it.
- It is not the schema of claims, sources, and decisions. That schema records what people say and what it rests on. This one records persons, functions, and the graphs they form.

The structural reading is the ontology. The metaphorical reading is a way to speak it. A change to the types or the edges is a change to the ontology, and it stays revisable.

## Two readings

The same structure has two readings. They stay separate.

| Reading | Who it is for | What it does |
|---|---|---|
| Structural | Researchers and machines | Names parts and edges. Carries no feeling and no cultural picture. This is the record. |
| Metaphorical | People | Uses poetic and cultural words so a person can feel the same structure. This is a reading of the record. It is not a second structure. |

Rules:

1. The structural name is the name of the part.
2. A metaphorical name may be used only after the structural name is in view.
3. A research note, a machine state, and a simulation use structural names only.
4. A film, a speech, and a public image may use metaphorical names.
5. One sentence does not mix the two as if they were one measurement.
6. A metaphor does not add a part. A poetic word with no row below is not in the foundation yet.
7. The structural reading is built so it can be tested. It is not, by itself, a tested theory.

Entry-level pages of this repo stay in the structural reading ([agents.md](../agents.md) rule b). Metaphor belongs in the film and in this paired table.

## Parts

| Structural name | What it is | Metaphorical name |
|---|---|---|
| Person-graph | A graph. It differs between people. It can change. The required inner nodes are not listed. | The person inside |
| Function | Reads an input and writes a current view. Also writes an output. Drawn, in the other reading, as a boundary around the person-graph. | Membrane |
| Input | What arrives at a function. | Feed |
| Attribution | What a function adds that was not in the input. The list of kinds is open. | Drawing. A threat-attribution may be called a demon. A value-attribution may be called an angel. Other kinds include danger, goodness, and understanding. |
| Output | What a function gives off. Another function can take it as an input. | Signal. A moral display is one output. Competence, harmlessness, and belonging are others. "Virtue signaling" is a cultural name for one moral display, not a measurement. |
| Container | A function that contains functions. Same parts, larger scale. | Collective. A membrane around membranes. |
| Event | Something done. An event is not an attribution. This foundation does not say what follows from an event. | Act |
| Belief-system | A subgraph a function reasons from. It shapes what the function reads, what it attributes, and the feeling that follows. It can be private or shared. It can change. When it cannot change, inputs that do not fit are attributed away instead of settled. | A map, a compass, a lens. Ideology and religion are names for belief-systems. They are the same type. |

An attribution is not the thing it points at. An output is not proof of what it displays.

## Edges

Edges are directed. They can appear, thicken, thin, and go. Edge names are structural. The metaphorical reading may speak of them in its own words. The record uses the names in this table.

| Edge | From | To | Structural meaning | Metaphorical reading |
|---|---|---|---|---|
| `of` | Function | Person-graph | This function belongs to this person-graph. | The membrane is of the person. |
| `reads` | Function | Input | The function takes this in. | A feed arrives. |
| `attributes` | Function | Attribution | The function adds this. | The membrane draws. |
| `emits` | Function | Output | The function gives this off. | A signal leaves the outside of the membrane. |
| `reaches` | Output | Function | Another function receives it as an input. | Another membrane reads the signal. |
| `contains` | Container | Function | A larger function holds smaller ones. | A membrane forms around membranes. |
| `settles` | Function | Person-graph | An input or an attribution may become part of the person-graph. Slow. Optional. | Something passes through the membrane and stays. |
| `reasons-from` | Function | Belief-system | The function uses this subgraph as the place reasoning starts. | The membrane looks through this lens. |

There is no edge from one person-graph into another. Contact leaves through a function and arrives at a function.

An output does not enter a person-graph by itself. Only `settles` does that, and only over time.

An edge that exists may carry a weight: how strong that present link is. A weight grades what arrived. It does not stand in for an item that never arrived. A missing item has no edge. If someone later brings that item, it can become a node. The tally does not invent it.

## Scales

The same parts repeat. In the structural reading, a container holds functions. In the metaphorical reading, a membrane holds membranes. The image of that repetition is a fractal. The image is a way to see. It is not a claim about the universe.

A container can form when inner functions keep exchanging the same outputs. A container can thin when that exchange stops. Formation and thinning are events in the picture. They assign no value.

## Labels

A label is a cultural name for a pattern in a container. Labels belong to the metaphorical reading. The structural record may store a label as a string attached to a container or a belief-system. The label does not define the part, and it is not an established mechanism.

| Label | Pattern it has been used for |
|---|---|
| Echo chamber | Inner functions mostly return the same outputs to each other. |
| Mass formation | One shared attribution moves many person-graphs at once. |
| Collective psychosis | A shared attribution has come apart from what is outside the container. |
| Ideology | A belief-system held as the place reasoning, judgment, and feeling start. Often shared. Often rigid. |
| Religion | A belief-system of that same type, carried as a tradition. |

## Belief

A belief-system is not the person-graph and not the function. It is a subgraph the function reasons from. Ideology and religion are labels for that type. One is not a corrupted form of the other.

Through it, the function does three ordinary things. It reads an input as the system allows. It attributes a judgment. It sets a feeling, so the system works as a regulator, not only as a description.

A belief-system can be revised. `settles` can still change the person-graph. A rigid one refuses that. What does not fit is drawn instead: a demon, an angel, or a sense of having understood. Rigidity is a pattern of edges, not a moral kind of person.

A belief that the belief-system is finished is the error already named. The system can be a compass. It cannot be the last map.

## Pathway

A pathway is a chain of edges across functions. It is the part that can be a threat. A person-graph is not that part.

A threat-pathway has three marks. Each mark is a claim. Each can be disputed.

1. An output leaves a function without inputs that support it, or the inputs are events of fabrication. A record that does not match what it claims to record is this kind of input. In the metaphorical reading this is false information.
2. That output reaches other functions and settles into other person-graphs. Inner graphs change.
3. Edges in the container are rearranged. Some outputs gather toward one place. Harm shows up as events on other graphs.

The test that this is a system: remove any one person-graph, and the pathway still carries the output. The chain is the object. The person is not.

A person-graph can sit at the start of such a pathway. The pattern, when it repeats, is a function that emits unsupported outputs and rearranges edges toward its own outputs, while harm events land elsewhere. Clinical words such as psychopathy are a label for that pattern, in the metaphorical reading. The label is a claim beside the pathway. It is not a node type, not a standing score, and not a diagnosis the record makes. The same person-graph can be read with other maps. The pathway remains either way.

Fabricated records in medicine are one place this picture is easy to see. A made-up input is read as a record. Functions pass it on. Attributions settle into practice. Harm events arrive at people who never made the record. Pointing at a personality is one reading of the start of the chain. The chain is what the graph can show.

What can be looked at, without a verdict:

- How many functions an unsupported output reaches.
- How many person-graphs it settles into.
- Whether the chain remains after one person-graph is removed.
- Which harm events sit downstream.
- The weight of the edges that exist.

None of these is a score of a person. A highlighted pathway is a drawing until the edges are there to count.

## Picture

Two ways to show the same frame.

**Structural frame**, for a researcher or a machine. Nodes are person-graphs, functions, inputs, attributions, outputs, containers, events, and belief-systems. Edges are the names above. Icons may mark `reads`, `attributes`, and `emits`. A pathway may be lit when its edges are present. Icons do not mark a person as a type. State is data.

**Metaphorical frame**, for a person. A small graph sits inside a ring. Signals leave the ring. A larger ring can form around rings. Demons, angels, and other drawings appear on the inside. Learned displays appear on the outside. A body condition a person offers, such as hunger or an injury, may appear as an icon. Color and the chance to open a node belong to this frame. Color is not a moral grade. The film uses this frame.

Motion, in either frame, can follow a game-of-life image: local rules, patterns that arise, no value painted on the first frame.

1. An input can arrive.
2. A function can attribute.
3. A function can emit.
4. An output can reach another function.
5. Repeated exchange can grow a container.
6. When the exchange stops, the container can thin.
7. An attribution can be withdrawn. What remains may be a person-graph, a situation, or an open question.
8. No rule assigns a moral value.

Meaning can be laid on later, in the metaphorical reading. It stays removable. The structural record keeps the parts either way.

## What this is for

The film floats on the metaphorical reading. Researchers and machines use the structural reading of the same parts. Neither reading finishes the picture.

A public discourse layer, if one is built, would be free, public, and open source. People fund it by giving. There is no fee. It surfaces records and connects them in more than one arrangement. An arrangement is not a decision. The layer does not decide. There is no split of responsibility among trainers, payers, and users, because those are not roles that issue a verdict here.

A container may be a sphere: people of one age, one kind of work, or another class, talking together. A sphere is a scoped ontology — its own rule table, its own membrane, its own aggregation floor, its own verdict vocabulary. A place is where it happens to meet. It is not a gate. Everyone may talk.

## Inside the person-graph

The inner nodes are not chosen. Many traditions have offered a map. A map is a candidate labeling. It is not the person-graph. Maps disagree, and the disagreement stays.

| Map | Reading | Where it sits | What is unsettled |
|---|---|---|---|
| Five-factor personality inventories | Structural candidate | Trait-nodes inside a person-graph | Schmitt and colleagues (2007) found the five-factor form across 56 nations in one inventory. Laajaj and colleagues (2019) found that face-to-face surveys in 23 low- and middle-income countries often fail to recover those five factors. The instrument is not a world node-set. |
| Jungian archetypes | Metaphorical | Recurring figures. They may be shared attributions across many functions, rather than private nodes. | Not a validated inventory of one person. |
| Kabbalah, the tree of the sefirot | Metaphorical | A graph of qualities with paths between them. | A mystical map. Not a measurement of a person. |
| Buddhist five aggregates | Structural counter-map | Form, feeling, perception, formations, consciousness, with no permanent self behind them (Stanford Encyclopedia, "Mind in Indian Buddhist Philosophy"). | It agrees that a person is a changing bundle. It refuses a fixed center. A person-graph that requires a self-node contradicts this map. |
| I Ching | Metaphorical | Situations of change, not a list of traits. | Closer to exchange and to `settles` than to inner nodes. |

Other religions and East Asian maps can be added as further rows. Adding a row does not retire the others.

A recurring family is a hypothesis, not a finding. Body, feeling, and habit appear often enough to keep in view. Some maps also place a center. The aggregate map forbids one. Perception is already the function in this foundation. A map that places the interpreter inside the person-graph contradicts the `of` edge. That contradiction stays visible.

## Scale

Two claims are easy to fuse. They are separate.

The image holds. The same parts can be drawn at the size of a person, a group, and a larger group. Particles form compounds. People form groups. A ring can form around rings. That compositional picture is fit to show. The fractal image belongs in the metaphorical reading.

The law does not hold. Particle dynamics, human conduct, and the solar system are not one mechanism. A social network is not, in general, a scale-free copy of a physical one. Broido and Clauset (2019) tested nearly 1000 networks. Strongly scale-free structure was rare. In their social networks, none met the strong tests. A log-normal fit the degree distribution as well as or better than a power law in 88 percent of the full set. Physics has real self-similarity in particular conditions, such as critical phenomena. Those conditions are not a permit to treat a conversation as an orbit.

Use the nested rings. Do not borrow the authority of physics for them.

A living cell is a closer picture than an orbit: a boundary, traffic across it, signals between cells. That picture belongs in the metaphorical reading. Resemblances of this kind do not run out. The foundation does not collect them. Nesting is the structural theme. The cell is one image of nesting.

## Zoom

A node at one scale may open into a graph at the next. This is a theme for the picture. It is not a schema being built.

A container can have a node that opens into a person-graph. Each person-graph may differ. A node inside a person-graph may itself open: body, history, inheritance, habit, or some other part a map proposes. Those inner graphs are not listed here. A society-sized graph and a person-sized graph use the same permission: zoom.

This is the answer to the center, for now. The foundation requires no center. A center is a claim a map makes, that one node or one subgraph matters more than the others. Another zoom can show that the supposed center is itself a graph, with no center of its own. Federation is the name for graphs joined without a required hub.

The film can show a zoom. The record does not yet store the inner graphs.

## The loop

The parts above are the vocabulary. This section names the cycle they form, so it can be iterated on as one artifact.

**Static layer.** Research, news, politics, norms, and other public sources that already exist and can be cited. This layer does not need federation — OpenAlex is already global. What federates is the derived graph each node extracts from it: claims, flags, axiom-candidates with provenance.

**Person-graph.** A function reads the static layer as its belief-system allows. It attributes. It emits. What settles becomes part of the person-graph. The person is assembled by biology, ideology, habit, inheritance — candidate maps, not a finished inventory. No map is the last map.

**Container.** Repeated exchange between functions grows a container. A sphere is one: a scoped ontology with its own rule table, membrane, aggregation floor, and verdict vocabulary. An institution is another — a container whose belief-system is written as law and whose functions are offices. Same parts. No new type needed.

**Institution-graph.** Institutions rewrite norms. Norms re-enter the static layer. The loop closes. The static layer is not outside the system; it is the system's memory, crystallized from prior passes of this same cycle.

**The function at the center of the loop.** Where slices cross membranes, something sifts and verifies in the instant. It is not a place. It is what the function does at every crossing — and every node can run its own copy. Distributed, not centralized. The sun is a name for the reaction, not a location.

**Federation.** Graphs join without a required hub. What crosses a boundary is a slice: approved extracts, derived claims, flags, axiom-candidates, each with provenance; membrane metadata naming the rules and the handoff-parameter version; a salted commitment binding it to the source set. What never crosses: raw transcripts, identities, blind tokens, individual-level data, anything below the aggregation floor. A display composes slices by aligning on shared entities and rendering both sides of any disagreement. Divergence is data.

**The creation story as microcosm.** This repo was built in a loop between one person and one machine with access to static information. Each conversation produced commits — events with provenance. The next conversation reads what settled. That is the smallest vertical slice of the object: one node, one function, no membrane required because there is only one voice. The membrane earns its existence when two voices must meet without either owning the record.

- When an input `settles`, and when it only passes.
- What people do about an event.
- Which containers receive which labels.
- The local rules of any simulation. The eight lines above are a sketch for the eye, not a program.
- Further metaphorical names. They enter by a new row, not by mixing into the structural column.
- Who approves the extracts inside a slice before it crosses a membrane. The direction is per-extract speaker consent; the mechanism is not specified.
- Whether the continuous-zoom film and the federation short piece are one film or two.
